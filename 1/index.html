CS180 Project 1: Images of the Russian Empire

Colorizing the Prokudin-Gorskii photo collection

Overview

Project Description

The goal of this project was to reconstruct color photographs from digitized RGB glass plate negatives taken by Sergei Mikhailovich Prokudin-Gorskii. Each glass plate contains three vertical grayscale exposures captured through blue, green, and red filters (in BGR order from top to bottom). By extracting these channel plates, determining the optimal spatial displacement offsets, and stacking them together, I automatically produced high-quality color images capturing early 20th-century Russia.

Part 1

Single-Scale Implementation (JPEG)

My initial approach uses a single-scale exhaustive search to align the Green and Red channels against the fixed Blue base channel. For each channel, every displacement vector within a bounded search window of [-15, 15] pixels in both $x$ and $y$ directions is tested using np.roll. All reported displacement vectors are formatted as (dx, dy) representing (horizontal shift, vertical shift).

I evaluated alignment quality using Normalized Cross-Correlation (NCC), computed by vectorizing the channel slices and normalizing by their mean and standard deviation:

NCC(I₁, I₂) = ∑[(I₁(x,y) - μ₁)(I₂(x,y) - μ₂)] / √[∑(I₁(x,y) - μ₁)² ∑(I₂(x,y) - μ₂)²]

To prevent scanning artifacts, dark borders, and frame edges from skewing the score, I cropped a 20% margin around the outer edges before calculating NCC. The offset yielding the highest NCC score is selected to stack the channels back into an aligned RGB image.

Part 2

Multi-Scale Pyramid Alignment (TIFF)

For high-resolution TIFF images, exhaustive searching over large pixel windows is far too slow. I implemented a multi-scale image pyramid alignment algorithm to process these efficiently. The strategy recursively downsamples the image channel plates by factors of 2 until reaching a base resolution. At the coarsest level, it performs a coarse search over a [-15, 15] range. As the recursion unwinds back up to full resolution, it scales the estimated displacement vectors by 2 at each level, pre-shifts the image, and runs a fine-grained refinement search within a narrow window of [-2, 2] pixels.

Overcoming Brightness & Contrast Mismatches (The Emir Issue):
When testing this pyramid pipeline on emir.tif, standard NCC on raw pixel intensities failed due to brightness discrepancies across color channels. To fix this, I updated my search functions to pass channel plates through Sobel edge detection (`scipy.ndimage.sobel`) to extract magnitude maps. Calculating NCC over structural edge gradients instead of raw pixel values restored accurate alignment across all channels.
