Part 1.1: Convolutions from Scratch!

In this section, 2D convolution was implemented from scratch using zero padding. First using a 4-loop method, then optimized into a vectorized 2-loop method, and finally compared against SciPy's built-in scipy.signal.convolve2d function.

1. Four-Loop Implementation

def convolve2d(im1, im2, padding=0):
    im2_height, im2_width = im2.shape
    im1_height, im1_width = im1.shape

    # pad
    padded_im1 = np.pad(im1, padding, mode='constant', constant_values=0)
    
    # get output dimensions based on padding type
    if isinstance(padding, tuple):
        pad_y = padding[0][0] + padding[0][1]
        pad_x = padding[1][0] + padding[1][1]
    else:
        pad_y = 2 * padding
        pad_x = 2 * padding
    
    # out_array
    output_height = im1_height - im2_height + 1 + pad_y
    output_width = im1_width - im2_width + 1 + pad_x
    
    # 0 fill from spec
    output = np.zeros((output_height, output_width))

    for i in range(output_height):
        for j in range(output_width):
            temp_sum = 0
            for k in range(im2_height):
                for l in range(im2_width):
                    temp_sum += padded_im1[i+k][j+l] * im2[k][l]
            output[i][j] = temp_sum
            
    return output

2. Two-Loop Implementation

def convolve2d_fast(im1, im2, padding=0):
    im2_height, im2_width = im2.shape
    im1_height, im1_width = im1.shape
    
    # pad
    padded_im1 = np.pad(im1, padding, mode='constant', constant_values=0)

    # get output dimensions based on padding type
    if isinstance(padding, tuple):
        pad_y = padding[0][0] + padding[0][1]
        pad_x = padding[1][0] + padding[1][1]
    else:
        pad_y = 2 * padding
        pad_x = 2 * padding

    # out_array
    output_height = im1_height - im2_height + 1 + pad_y
    output_width = im1_width - im2_width + 1 + pad_x
    
    # 0 fill from spec
    output = np.zeros((output_height, output_width))

    for i in range(output_height):
        for j in range(output_width):
            output[i][j] = np.sum(padded_im1[i:i+im2_height, j:j+im2_width] * im2)
    
    return output

Runtime Analysis & Boundary Handling

  • Four Loop Implementation: Has a time complexity of O(H×W×K×L) where H,W represent image dimensions and K,L represent kernel dimensions. The explicit nested loops make the algorithm clear, but execution is computationally expensive due to pure Python overhead.
  • Two Loop Implementation: Achieves significant speed improvements with O(H×W) outer loop complexity. It uses numpy.sum() for vectorized matrix element-wise multiplication on kernel patches, leveraging optimized underlying C libraries.
  • scipy.signal.convolve2d: A highly optimized implementation achieving a 10-100x speedup. It automatically switches to FFT-based convolution for larger filter kernels.
  • Boundary Handling: Zero padding preserves output dimensions (same mode) and prevents edge artifacts. All three functions produce identical output images when given the same padding.

Part 1.2: Finite Difference Operator

To detect edges, we first compute the partial derivatives of the original Cameraman image in the horizontal ($x$) and vertical ($y$) directions using finite difference operators $D_x = [1, 0, -1]$ and $D_y = [1, 0, -1]^\top$. Combining these partial derivatives gives the gradient magnitude: $\text{Magnitude} = \sqrt{D_x^2 + D_y^2}$. Finally, thresholding the gradient magnitude produces a binarized edge map.

Implementation

def run_part_1_2(output_dir: str):
    img_path = "cameraman.png"
    cameraman_img = cv2.imread(img_path, cv2.IMREAD_GRAYSCALE)
    if cameraman_img is None:
        raise FileNotFoundError(f"Could not find '{img_path}'.")
    cameraman = cameraman_img.astype(np.float64) / 255.0
    
    # Define finite difference operators
    Dx = np.array([[1, 0, -1]], dtype=np.float64)
    Dy = np.array([[1], [0], [-1]], dtype=np.float64)
    
    # Compute partial derivatives via 2D convolution
    dx_img = scipy.signal.convolve2d(cameraman, Dx, mode='same', boundary='symm')
    dy_img = scipy.signal.convolve2d(cameraman, Dy, mode='same', boundary='symm')
    
    # Calculate gradient magnitude
    grad_mag = np.sqrt(dx_img**2 + dy_img**2)
    
    save_and_display(cameraman, os.path.join(output_dir, "13_cameraman_original.png"), "Original Cameraman")

Part 1.3: Derivative of Gaussian (DoG) Filter

To eliminate high-frequency noise (such as grass texture) prior to edge detection, we apply a Gaussian filter $G$. By the associative property of convolution, $(I * G) * D = I * (G * D)$, smoothing then differentiating is mathematically identical to convolving the image with a single pre-computed Derivative of Gaussian (DoG) filter.

Implementation

def create_2d_gaussian(size: int, sigma: float) -> np.ndarray:
    gaussian_1d = cv2.getGaussianKernel(size, sigma)
    gaussian_2d = np.outer(gaussian_1d, gaussian_1d.T)
    return gaussian_2d

def run_part_1_3(image_path: str, output_dir: str):
    # Load input image
    im = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE).astype(np.float64) / 255.0

    # 1. Create Gaussian Filter (15x15, sigma=2.0)
    gaussian_filter = create_2d_gaussian(15, 2.0)

    # 2. Method 1: Gaussian Smoothing then Finite Differences
    im_smoothed = scipy.signal.convolve2d(im, gaussian_filter, mode='same', boundary='symm')
    Dx = np.array([[1, 0, -1]], dtype=np.float64)
    Dy = np.array([[1], [0], [-1]], dtype=np.float64)

    dx_smoothed = scipy.signal.convolve2d(im_smoothed, Dx, mode='same', boundary='symm')
    dy_smoothed = scipy.signal.convolve2d(im_smoothed, Dy, mode='same', boundary='symm')
    grad_mag_smoothed = np.sqrt(dx_smoothed**2 + dy_smoothed**2)

    # 3. Method 2: Derivative of Gaussian (DoG) Filters directly
    dog_x_filter = scipy.signal.convolve2d(gaussian_filter, Dx, mode='full')
    dog_y_filter = scipy.signal.convolve2d(gaussian_filter, Dy, mode='full')

    dx_dog = scipy.signal.convolve2d(im, dog_x_filter, mode='same', boundary='symm')
    dy_dog = scipy.signal.convolve2d(im, dog_y_filter, mode='same', boundary='symm')

    # Thresholding selected at 0.07

    # Verification of numerical equality
    diff_dx = np.max(np.abs(dx_smoothed - dx_dog))

Part 2.1: Image Sharpening ("Unsharp Masking")

An image can be sharpened by extracting its high-frequency content and adding a scaled version back to the original image. The high-frequency component is obtained by subtracting a low-pass Gaussian blurred image from the original: $$\text{High Frequencies} = I - (I * G)$$ By scaling this detail by a factor $\alpha$, the sharpened image is: $$\text{Sharpened} = I + \alpha (I - I * G) = I * ((1 + \alpha)\delta - \alpha G)$$ where $\delta$ is the unit impulse kernel and $G$ is the 2D Gaussian filter. This allows us to combine blurring and detail addition into a single unsharp mask filter operation.

Implementation

def unsharp_mask_filter(size: int, sigma: float, alpha: float) -> np.ndarray:
    """Computes single unsharp mask kernel: (1 + alpha)*delta - alpha*G"""
    gaussian = create_2d_gaussian(size, sigma)
    impulse = np.zeros_like(gaussian)
    impulse[size // 2, size // 2] = 1.0
    return (1.0 + alpha) * impulse - alpha * gaussian

def sharpen_image(im: np.ndarray, sigma: float = 1.5, alpha: float = 1.0) -> np.ndarray:
    """Sharpens an image using the single-pass unsharp mask convolution kernel."""
    kernel_size = int(2 * np.ceil(3 * sigma) + 1)
    kernel = unsharp_mask_filter(kernel_size, sigma, alpha)
    
    if im.ndim == 2:
        sharpened = scipy.signal.convolve2d(im, kernel, mode='same', boundary='symm')
    else:
        sharpened = np.zeros_like(im)
        for c in range(im.shape[2]):
            sharpened[:, :, c] = scipy.signal.convolve2d(im[:, :, c], kernel, mode='same', boundary='symm')
            
    return np.clip(sharpened, 0.0, 1.0)

Part 2.2: Hybrid Images

Hybrid images combine the low-frequency spatial components of one image with the high-frequency components of another. Because human visual perception processes high frequencies at close distances and low frequencies from farther away, the high-frequency image dominates when viewed up close, while the low-frequency image becomes clearly visible at a distance.

Mathematically, given a low-frequency image $I_{\text{low}}$ filtered with Gaussian parameter $\sigma_{\text{low}}$ and a high-frequency image $I_{\text{high}}$ filtered with $\sigma_{\text{high}}$, the hybrid image is computed as: $$\text{Hybrid} = (I_{\text{low}} * G_{\sigma_{\text{low}}}) + \left( I_{\text{high}} - (I_{\text{high}} * G_{\sigma_{\text{high}}}) \right)$$

Implementation

def create_hybrid_image(im1: np.ndarray, im2: np.ndarray, 
                        sigma_low: float, sigma_high: float) -> np.ndarray:
    """
    Creates a hybrid image by blending low frequencies of im1 with 
    high frequencies of im2.
    """
    # 1. Compute low frequencies for Image 1
    kernel_low_size = int(2 * np.ceil(3 * sigma_low) + 1)
    g_low = create_2d_gaussian(kernel_low_size, sigma_low)
    im1_low = scipy.signal.convolve2d(im1, g_low, mode='same', boundary='symm')

    # 2. Compute high frequencies for Image 2 (Original - Blurred)
    kernel_high_size = int(2 * np.ceil(3 * sigma_high) + 1)
    g_high = create_2d_gaussian(kernel_high_size, sigma_high)
    im2_blurred = scipy.signal.convolve2d(im2, g_high, mode='same', boundary='symm')
    im2_high = im2 - im2_blurred

    # 3. Combine low and high frequency channels
    hybrid = im1_low + im2_high
    return np.clip(hybrid, 0.0, 1.0)

Part 2.3: Gaussian and Laplacian Stacks

To isolate image details at different spatial scales, we build Gaussian and Laplacian stacks. Unlike an image pyramid, images in a stack retain their original spatial resolution (no downsampling).

A Gaussian stack $\{G_0, G_1, \dots, G_N\}$ is formed by repeatedly blurring the image with exponentially increasing $\sigma$ values ($G_0 = I$, $G_{k+1} = G_k * G_{\sigma_k}$). The Laplacian stack $\{L_0, L_1, \dots, L_N\}$ isolates specific frequency bands by taking differences between consecutive Gaussian levels: $$L_k = G_k - G_{k+1} \quad \text{for } 0 \le k < N, \quad \text{and } L_N = G_N$$ Because $I = \sum_{k=0}^N L_k$, the original image can be perfectly reconstructed by summing all Laplacian levels and the low-frequency residual $G_N$.

Implementation

def build_gaussian_stack(im: np.ndarray, num_levels: int, initial_sigma: float) -> list:
    """Builds a Gaussian stack without downsampling."""
    stack = [im.copy()]
    current_im = im.copy()
    for i in range(num_levels - 1):
        sigma = initial_sigma * (2 ** i)
        kernel_size = int(2 * np.ceil(3 * sigma) + 1)
        g_kernel = create_2d_gaussian(kernel_size, sigma)
        
        if im.ndim == 2:
            current_im = scipy.signal.convolve2d(current_im, g_kernel, mode='same', boundary='symm')
        else:
            current_im = np.zeros_like(current_im)
            for c in range(im.shape[2]):
                current_im[:, :, c] = scipy.signal.convolve2d(stack[-1][:, :, c], g_kernel, mode='same', boundary='symm')
        stack.append(current_im)
    return stack

def build_laplacian_stack(gaussian_stack: list) -> list:
    """Builds a Laplacian stack from a Gaussian stack."""
    laplacian_stack = []
    num_levels = len(gaussian_stack)
    for i in range(num_levels - 1):
        laplacian_stack.append(gaussian_stack[i] - gaussian_stack[i+1])
    laplacian_stack.append(gaussian_stack[-1].copy())  # Residual level
    return laplacian_stack

Part 2.4: Multiresolution Blending

Multiresolution blending (Burt and Adelson) seamlessly combines two images $A$ and $B$ across multiple spatial frequency bands using a soft mask $M$. By constructing a Gaussian stack for the mask $M_k$ and Laplacian stacks for both images ($L_k(A)$ and $L_k(B)$), each frequency band is blended independently: $$B_k = M_k \cdot L_k(A) + (1 - M_k) \cdot L_k(B)$$ Summing all blended levels $\sum B_k$ yields a composite image where sharp details transition over a narrow boundary while smooth lighting and color variations transition over a wide, seamless seam.

Implementation

def multiresolution_blend(im1: np.ndarray, im2: np.ndarray, mask: np.ndarray, num_levels: int = 5, sigma: float = 2.0) -> np.ndarray:
    """Blends two images using Laplacian stacks and a smoothed mask Gaussian stack."""
    g_stack1 = build_gaussian_stack(im1, num_levels, sigma)
    g_stack2 = build_gaussian_stack(im2, num_levels, sigma)
    mask_stack = build_gaussian_stack(mask, num_levels, sigma)
    
    l_stack1 = build_laplacian_stack(g_stack1)
    l_stack2 = build_laplacian_stack(g_stack2)
    
    blended_stack = []
    for k in range(num_levels):
        m_k = mask_stack[k]
        if im1.ndim == 3 and m_k.ndim == 2:
            m_k = np.repeat(m_k[:, :, np.newaxis], 3, axis=2)
        b_k = m_k * l_stack1[k] + (1.0 - m_k) * l_stack2[k]
        blended_stack.append(b_k)
        
    final_blend = np.sum(blended_stack, axis=0)
    return np.clip(final_blend, 0.0, 1.0)

Conclusion & Key Takeaways

The most important insight I gained from this project is that almost all frequency-based image processing comes down to a single fundamental operation: blurring and subtracting. While image sharpening, hybrid images, and multiresolution blending appear distinct on the surface, seeing them through the lens of frequency decomposition reveals that they are all variations of the exact same principle. Sharpening adds back the high frequencies that blurring removes; hybrids combine the high frequencies isolated from one image with the low frequencies retained by another; and Laplacian stacks repeatedly apply this blur-and-subtract pipeline across multiple scales.

Beyond conceptualizing this unified framework, working directly with frequency bands transformed how I reason about parameters and visual perception. Instead of guessing $\sigma$ values, understanding that a Gaussian cutoff scales inversely with $\sigma$ ($\approx 0.19/\sigma$ cycles per pixel) allowed me to select parameters intentionally based on an image's structural content—such as realizing high-detail textures like fur or whiskers must serve as the high-frequency source because low-pass filtering strips them away completely.

I was also struck by practical nuances in the implementation: how convolution's associative property makes blurring and taking derivatives mathematically identical to a single Difference of Gaussians (DoG) filter (yielding identical results to machine precision $10^{-15}$), how critical boundary padding and alignment are to preventing edge artifacts, and how mask Gaussian stacks are essential for hiding seams in blending. Furthermore, I observed that color predominantly resides in low frequencies; color in high-frequency channels has a minimal visual impact, whereas in blending, color alignment between sources dictates whether the composition looks natural or mismatched.

Ultimately, isolating these spatial frequencies firsthand bridged the gap between lecture theory and hands-on practice, proving that complex visual effects rely on the precise mathematical manipulation of underlying image signals.
